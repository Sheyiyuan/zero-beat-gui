# ADR-0009：Android 原生无损封装与标签

- 状态：接受；替代 2026-11-16 的完整媒体流直接保存方案
- 更新：2026-11-18

## 决策

Android 与桌面共用 Go HTTP 传输、资源身份校验、续传、下载队列和索引。Android 通过 cgo 动态加载 `libzeroremux.so`，调用固定 FFmpeg 7.1.1 的 libavformat／libavcodec／libavutil 完成音频包复制，并写入歌名、歌手、专辑。Android 不启动外部 ffmpeg，也不在 Dart 另建下载队列。

只处理可读取的完整音频资源；不把播放列表、缺初始化段的碎片或未知容器伪装为音频。输出按实际封装器生成，重新打开验证音轨编码与标签，成功后由 Go fsync、原子替换并登记索引。取消、损坏或写入失败不登记成功，强制重下失败保留旧完成文件。

续传使用强 ETag 或 Last-Modified 配合 If-Range；无可用校验信息时重新下载。服务端忽略 Range 或资源变化时不能将新资源接到旧片段后。临时文件包含分 P 身份，避免同视频不同音轨混用。

## 构建与分发

`native/remux/ffmpeg-7.1.1.sha256` 固定源码摘要；本轮已使用 FFmpeg 官网发布密钥验证源码签名，指纹为 `FCF9 86EA 15E6 E293 A564 4F10 B432 2F04 D676 58D8`。`scripts/build-android-remux.sh` 固定 NDK r28c、API 24、arm64，只启用所需格式，不启用 GPL／nonfree／version3 组件。

构建保留精确源码、配置、静态库、封装对象与 LGPL 文本，详见[原生组件说明](../../native/remux/README.md)。APK 检查器要求核心、封装库、播放器依赖同时存在，验证 AArch64、动态依赖与 16KB 对齐。缺少原生组件时构建失败，不回退为无标签的原始下载。

## 存储与导出

完成文件保存在应用私有目录。Android 10+ 可导出到 MediaStore 的 `Music/零拍`，所有支持版本均可用系统文件选择器另存，也可分享。导出失败只清理此次导出的不完整文件，保留私有目录中的完成下载。

SAF 目录歌单保留系统 URI 与持久授权，由 ContentResolver 枚举／读取；核心继续计算身份和维护索引。移除歌单只删索引，不删源文件。目录失联保留索引，重新授权后重扫。

真机发现原始 SAF 描述符供原生库重新打开时不兼容，因此扫描与播放前将授权内容完整暂存到应用私有文件，提供普通可 seek 描述符；不将 URI 转成猜测的共享存储路径。句柄关闭时删除暂存文件，下次进程首次打开资源时回收遗留缓存，Activity 重建不提前释放后台播放器文件。此路径会增加与文件大小相关的临时磁盘占用及初次读取时间；空间不足必须报告失败，不能登记不可读音频。

## 验收边界

桌面 ffmpeg 的标签和包哈希回归不能替代 Android 原生封装执行。必须分别记录原生组件检查、APK 打包检查、真实下载标签回读、权限撤销、导出失败和离线播放。设备未连接时，真机项目保留未验证。完整记录见[功能验收](../17-full-gui-parity.md)。
