# GUI 产品与交互规格

本页把现有功能和 SVG 预览转成可实施的页面规格。当前为设计与开发约定，不代表 Flutter 页面已经实现；实际工具链见[开发环境](12-development-environment.md)，开发依赖与验收见[实施计划](14-implementation-plan.md)。GUI 完成后再与 TUI / core 0.8.0 联合发布。

## 产品范围

零拍是把 B 站、网易云和本机音乐放在同一曲库里的播放器。第一版围绕「找到内容 → 播放 → 看歌词或相关内容 → 保存到自己的歌单」形成闭环，保留 TUI 已有数据和播放行为。

| 能力 | GUI 首版行为 | 边界 |
| --- | --- | --- |
| 曲库与歌单 | 本地、混合、平台导入；桌面文件夹歌单 | 文件夹与仅本机数据不跨设备传输；Android 文件夹扫描后续做 |
| 搜索 | 本地、B 站、网易云、合并结果；分页与来源标签 | 部分音源失败时保留其它结果 |
| 播放 | 队列、模式、音量、片段、歌词、断点恢复 | Go 决定播放顺序；恢复队列后不自动出声 |
| 评论与推荐 | 只读评论、相关推荐、相似歌曲、播放与入队 | 不发评论、不点赞、不回复；保留平台登录与风控提示 |
| 主页 | 歌手作品、UP 主投稿、用户公开歌单与节目 | 不关注、订阅或修改平台资料 |
| 播客电台 | 热门电台、节目列表、主播、节目播放与评论 | 节目不能写入云端歌曲歌单；不购买付费内容 |
| 账号 | 按平台扫码、状态、退出与过期提示 | 原始 cookie 不进入页面状态或日志 |
| 下载 | 桌面既有能力；Android 使用通过样本验证的媒体流 | Android 不依赖外部 ffmpeg，支持矩阵通过原型确定 |
| 同步 | 歌单／键位／注释、冲突处理；登录态单独开关 | 登录态默认关闭，每设备自行开启 |

## 信息架构

**桌面与移动端分别设计。** 共用领域模型、颜色／字体 token 和业务规则；导航结构、页面组成、操作密度、返回方式分别实现。GUI 鼠标／触控优先，只为常用操作提供快捷键；TUI 的全键盘要求不迁移到 GUI。

| 维度 | 桌面设计 | Android 设计 |
| --- | --- | --- |
| 一级导航 | 左侧常驻导航与歌单 | 曲库／发现／我的底部导航 |
| 内容展示 | 多栏列表，当前页面可并排打开队列／评论 | 单任务页面，长内容独立页，短操作使用底部面板 |
| 播放 | 常驻底栏，独立歌词／正在播放区域 | 迷你播放条进入全屏播放，通知与锁屏控制 |
| 作者选择 | 点击播放条作者，浮层选择或直接进入 | 点作者打开底部选择面板，进入独立主页 |
| 操作菜单 | 行按钮、右键、批量操作条 | 行更多按钮、长按选择与触控操作面板 |
| 输入 | 鼠标与常用快捷键；支持窗口缩放 | 触控、软键盘、系统返回与安全区 |
| 自适应 | 桌面窄窗收起侧栏，不变成手机导航 | 横屏／大字体单独验证，不缩放桌面布局 |

### 桌面

左侧固定主导航和歌单列表；中间为当前页面；右侧按需显示评论、推荐或队列；底部为常驻播放条。当前播放曲目、列表选中项和右侧内容目标分别保存，不因焦点移动而偷偷切换。

- 曲库：最近使用、本地歌单、混合歌单、平台歌单与桌面文件夹。
- 发现：搜索、相关推荐、热门电台；平台没有提供的内容不伪造榜单。
- 下载：任务、失败原因、已下载内容与存储位置。
- 账号与设置：音源账号、播放偏好、快捷键、跨设备同步。
- 正在播放：点击底栏封面／标题展开，包含歌词、作者、评论／推荐入口。

右侧内容关闭后焦点回到打开它的控件；窗口变窄时改为内容抽屉或独立页面，不挤压列表到不可读。桌面主列表使用可见行渲染，保留滚动位置和选中 ID。

### Android

底部三个一级入口为「曲库」「发现」「我的」。迷你播放条位于底部导航上方，进入正在播放后使用完整页面。评论、作者列表、队列等短流程可以用底部面板；长作品列表、歌手／用户主页与电台使用独立页面。

- 曲库：歌单与本机已下载内容；导入平台歌单从明确按钮进入。
- 发现：搜索与热门电台；从播放页也能进入当前曲目的推荐。
- 我的：账号、下载、同步和设置。
- 系统返回先退出当前面板，再回上层页面；返回不会暂停当前播放。
- 手机页面保留顶部标题、返回及必要操作；避免把桌面三栏等比例缩小。

### 路由与上下文

下列是 Flutter 内部路由约定，不是 RPC 方法或平台 URL：

| 页面 | 必须携带的上下文 | 返回时保留 |
| --- | --- | --- |
| 曲库／歌单 | playlist ID、来源、过滤词 | 选中曲目、滚动位置、已加载分页 |
| 搜索 | 搜索范围、query、请求代次 | 每音源结果、页码、当前选择 |
| 正在播放 | 当前播放快照 | 展开前页面与焦点 |
| 评论／推荐 | 打开时的曲目 Ref、tab、page | 评论滚动位置；换目标才重置 |
| 作者选择 | 按下入口时的曲目 Ref、去重作者列表 | 多作者选择行；单作者不建立选择页 |
| 主页／电台 | BrowseRef（source、kind、ID） | 父页页码、列表选择与滚动位置 |
| 同步冲突 | 当前事务 ID、实体 ID | 选择草稿；事务变化必须重新读取 |

界面标题展示当前内容目标。播放过程中自动换歌，不会把正在读的评论或主页切到下一首；用户重新点击「当前作者」或「评论」才获取新的目标快照。

## 页面规格与动作

### 曲库、搜索与队列

曲目行包含标题、作者、来源和时长；桌面宽度允许时增加专辑。选中、高亮当前播放、已下载、不可播放分别表达，不能只用同一种红色表达所有状态。

- 桌面单击选择，双击或行播放按钮播放，`Enter` 可播放选中项；手机点曲目播放，行更多按钮打开动作面板，长按进入选择。
- 行菜单提供播放、下一首、加入队列、加入歌单、评论、推荐和「此曲作者」。不可用动作隐藏或附明确原因。
- 可播放页面共用曲目动作组件，避免推荐页与电台页有不同的加歌语义。
- 当前播放作者入口始终使用当前曲目；行菜单「此曲作者」始终使用该行，两者标签与提示要可区分。
- 批量选择时显示数量和批量操作条；换歌单清空选择，异步刷新按稳定 ID 保留仍存在的选择。
- 删除队列当前曲目、清空队列等行为交由 Go controller；Flutter 不自行计算下一首。
- 混合歌单「移除」表示隐藏继承曲目；文案说明不修改源歌单。文件夹歌单不展示手动增删曲目。

### 正在播放与歌词

底栏始终保留播放／暂停、前后曲、进度、标题作者与队列入口；窄屏减少次要控件，音质、增益与睡眠定时放在「更多」。

歌词以当前行为焦点，翻译跟随原文。手动滚动后暂停自动跟随，提供「回到当前行」；点按时间行跳转，成功位置以核心事件为准。无歌词显示「暂未找到歌词」及更换来源入口；纯文本来源不伪装成可逐行同步歌词。

拖动进度只更新拖动预览，结束拖动后提交 seek；收到核心校准结果前不触发重复 seek。暂停状态下 seek 保持暂停。错误、缓冲、暂停、播放中各自显示，不能用旋转图标代替所有状态。

### 评论与相关推荐

- 评论卡片显示作者、时间、正文、点赞数与可得回复数；点赞数是信息，不画成可点击点赞按钮。
- 点击作者打开评论作者主页；无 AuthorRef 时头像／名字为普通文字。
- 页码以返回值为准；`has_more=false` 不展示有效的下一页操作。B 站匿名预览显示登录提示，不把少量结果当网络错误。
- 推荐条目沿用通用曲目操作；入队结果反馈为「已加入队列」，不跳走、不停止当前播放。
- 请求失败保留已显示内容，追加错误和重试入口；切换目标时清理旧目标内容，避免标题与正文来自不同歌曲。
- 内容只读；不出现发表评论输入框、关注、点赞、回复等尚未实现的按钮。

### 作者与用户主页

「当前作者」基于调用时的播放曲目，暂停也可用。去重后只有一位作者直接进入；多位显示选择列表；无当前曲目提示先选择播放内容，无可用作者时给出空态。播客只把主播计为作者，电台通过单独的「所属电台」入口进入。

主页头部展示接口实际返回的标题、描述、封面；未返回的粉丝数、认证、关注按钮不占假位置。作品／公开歌单／节目根据 BrowseEntry 的类型进入或播放；不从标题文本猜数据类型。B 站 `-352` 显示平台暂时拒绝访问与重试，不能宣称登录一定能解决。

### 播客与电台

发现页提供热门电台，进入电台后展示资料、节目列表和主播入口。节目保留 `program:<ID>` 身份，加入本地歌单后再次进入仍能打开节目评论和主播；音频解析得到的 mainSong ID 不成为页面或歌单 ID。

节目加入歌单时仅允许本地／混合目标；云端歌曲歌单显示不可用原因。若平台返回不可播放或付费限制，保留节目详情并展示原因，不自动购买或变更账号。

### 账号与同步

账号页按音源能力展示，文件夹／本机音乐不出现扫码按钮。扫码过程区分等待、已扫描、过期、成功；离开时停止轮询，回到页面重新查询账号状态。退出某音源说明该源歌单将冻结、本地歌单与队列保留。

同步页顺序为：仓库与连接状态 → 手动同步／上次结果 → 自动同步 → 登录态同步 → 冲突／高级设置。

- 首次设置明确提示歌单与注释明文保存；SSH/HTTPS 认证与登录态口令分别呈现。
- 登录态开关默认关闭；关闭时隐藏口令和密钥管理操作，不显示缺密钥警告。
- 开启是本机选择；另一设备仍要单独开启。关闭时说明已有远端密文和历史仍保留。
- v2／v3 兼容及原地升级由 core 决定；UI 展示结果，不自行改元数据。
- 冲突页并排或上下比较本地／远端，支持实体级选择。最终提交前重新验证事务，数据变化后作废旧选择并提示刷新。

## 常用快捷键与无障碍

桌面以鼠标和可见按钮为主要路径，只为高频操作提供快捷键，不要求每项行为都有键位或能纯键盘走完整个应用。Flutter 的标准焦点和 Semantics 保留，分派快捷键前检查输入焦点与弹层状态。

| 操作 | 默认行为 |
| --- | --- |
| `Space` | 非输入状态播放／暂停；按钮获得焦点时遵循按钮自身动作 |
| `Ctrl/Cmd+F` | 聚焦搜索 |
| `Ctrl/Cmd+←` / `Ctrl/Cmd+→` | 非输入状态上一首／下一首 |
| `+` / `-` | 非输入状态调高／调低音量 |
| `Enter` | 播放桌面列表选中项或激活当前按钮 |
| `u` | 非输入状态查看当前播放作者；也可直接点击播放条作者 |
| `Esc` | 关闭当前弹层或取消当前编辑 |

评论、入队、歌单与设置等操作通过可见按钮和菜单完成；不照搬 TUI 的 `i/I/O/E/e/a/N` 全套键位。`Tab` 仍按平台标准移动控件焦点，不用作全局换页。GUI 快捷键设置独立于 TUI，最多按明确的动作映射复用用户偏好，不修改 TUI 的配置或自动覆盖系统保留键。

Android 不显示桌面键帽，不依赖快捷键完成行为；通过点击、长按、底部面板和系统返回交互。

手机触控目标至少 48×48 逻辑像素；桌面图标按钮提供可聚焦区域和提示。颜色不单独承担来源、错误或选中含义。字体放大时按钮文案与正文重排；评论完整可读，歌曲长标题可省略但提供完整语义标签。TalkBack 读出曲名、作者、来源及当前播放状态，进度通知节流，避免每 250ms 打断阅读。

## 异步状态与错误

所有加载页面使用相同状态结构：`idle / loading / ready / empty / failure`，另保存刷新状态，避免刷新时把旧内容清空。每个请求携带 target、page 和 generation；关闭、换目标或新搜索时递增 generation 并尽力取消。结果回来后再次比较，不能仅依赖网络取消成功。

| 状态 | 页面行为 | 可用动作 |
| --- | --- | --- |
| 初次加载 | 保留页面标题与返回，内容区域占位 | 返回／取消 |
| 空列表 | 描述当前范围确实无内容 | 改筛选、返回或对应新增入口 |
| 请求失败 | 显示可理解的原因；有旧内容时继续保留 | 重试、返回 |
| 登录过期 | 只影响对应平台，保留本地数据 | 重新登录、继续其它来源 |
| 平台限制 | 显示接口 notice／限制，不无限翻页或自动重试 | 返回、手动重试或有依据的登录入口 |
| 断开核心 | 标识连接已断开，禁用依赖核心的写操作 | 重连；重连后拉取快照，不重放旧播放／写命令 |

用户触发的失败在当前任务附近显示，下载与同步长期任务有可再次打开的记录。成功提示不抢焦点。网络失败不改变账号登录态，只有 core 明确报告过期时才更新账号。

## SVG 预览与实施约束

预览与设计 token 位于 GUI 仓库 `design/`。它们展示虚拟示例内容与布局，不会连接真实账号或代表已经可用的 Flutter 产品。实现时先复用颜色、间距和组件层级，再用 Flutter 自适应布局，不按 SVG 坐标绝对定位整个界面。

桌面与手机都必须验证长中文标题、双作者、无封面、无歌词、无结果、失败与登录态关闭状态。桌面验收鼠标主流程和常用快捷键；Android 单独验收触控、系统返回、软键盘与 TalkBack。页面实现后分别截图对照各自预览，不用一套截图或纯键盘全流程作为双端验收。
